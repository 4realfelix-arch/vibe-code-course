# Vibe Code Curriculum - Projects

This directory contains hands-on projects to apply what you've learned in the Vibe Code curriculum.

## Project List

### Beginner Projects (Module 1-2)

1. **Calculator App** - Build a command-line calculator
2. **Todo List Manager** - Create a task management system
3. **Number Guessing Game** - Interactive guessing game
4. **Contact Book** - Simple contact management
5. **Word Counter** - Analyze text files

### Intermediate Projects (Module 3)

6. **Library Management System** - OOP-based library manager
7. **Bank Account Simulator** - Banking operations with classes
8. **Inventory System** - Product inventory management
9. **Student Gradebook** - Track student grades and statistics
10. **E-commerce Cart** - Shopping cart implementation

### Advanced Projects (Module 4-5)

11. **Sentiment Analyzer** - NLP-based sentiment analysis
12. **Image Classifier** - Basic computer vision
13. **Chatbot** - AI-powered conversation bot
14. **Recommendation Engine** - Content recommendation system
15. **AI Assistant** - Personal AI assistant application

## How to Use

Each project includes:
- Project description and requirements
- Starter code template
- Step-by-step guide
- Solution code
- Extension challenges

## Getting Started

1. Choose a project appropriate to your skill level
2. Read the project description
3. Try to implement it yourself first
4. Check the solution if you get stuck
5. Complete extension challenges

Happy coding! 🚀
