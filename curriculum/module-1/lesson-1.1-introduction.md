# Lesson 1.1: Introduction to Programming

## Overview

Welcome to your first lesson in programming! In this lesson, you'll learn what programming is, why it's important, and write your first program.

## What is Programming?

Programming is the process of creating a set of instructions that tell a computer how to perform a task. It's like writing a recipe, but for computers!

### Key Concepts

1. **Code**: The instructions you write for the computer
2. **Programming Language**: The language you use to write code (we'll use Python)
3. **Execution**: When the computer runs your code
4. **Output**: The result of your program

## Your First Program

Let's write the classic "Hello, World!" program:

```python
print("Hello, World!")
```

This simple program tells Python to display the text "Hello, World!" on the screen.

## How Programs Work

1. **Input**: Data you give to the program
2. **Processing**: The program does something with the data
3. **Output**: The program shows you the result
